# Profile

This folder holds what AI Desk knows about you.

- **`profile.md`** — your saved profile. Created when you type `init`. It's kept out of version
  control (git-ignored) because it's your personal/business information.
- **`profile.template.md`** — the blank structure the assistant fills in. Don't edit unless you want
  to change what gets collected.

You can open `profile.md` and edit it by hand any time, or just tell the assistant "update my
profile — I now…" and it will keep it current. Re-run `init` to review everything.
