# Workspace

This is where your drafts and finished files land — emails, notes, research briefs, content, plans.
The assistant organizes things into subfolders as it goes (for example `emails/`, `notes/`,
`research/`, `content/`, `plans/`).

Everything here is **yours and private** — it's kept out of version control by default. Feel free to
open, edit, move, or delete anything. If it ever gets cluttered, just ask the assistant to tidy it
up.
